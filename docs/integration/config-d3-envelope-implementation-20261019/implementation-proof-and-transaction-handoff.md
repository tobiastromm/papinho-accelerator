## Ownership and lifecycle

Caller owns immutable inputs and exclusive disjoint outputs for each synchronous call; output contains no input pointers and survives input destruction. Callbacks have explicit synchronous/no-retain/no-reentry/lifetime contract; codec cannot be called from owner event loop/Stop. Bad pointer/range/capacity/overlap writes none; other failures clear safe completion/used metadata before validation, including hash/component failure, and never expose partial results. No heap/thread/lock/registry/pin or handle acquired by portable codec. Native BODY/hash calls use established adapters and their existing cleanup, no private-key generation/export/CA/store operation. No source, Session, owner or native process is closed by codec result.

Because no root participant or credit was acquired, codec outputs remain caller-owned even on UNKNOWN elsewhere; this slice does not introduce a timeout-based release path. Existing root Stop/retention/pin/reaper behavior is unchanged. No product linkage of ROOT8 library (actual Ninja server link edges saved); option OFF by default. Native component adapter linked only to offline regression executable, not server/root.
