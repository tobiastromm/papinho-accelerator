## Ownership and precise integration boundary

The codec owns no storage or resource and retains no pointer. Caller protects both immutable full images, disjoint output/metadata and synchronous nonreentrant hash/component contexts until return. Rejection does not expose a partial decoded image. No function performs I/O, acquires a pin/borrow, publishes CURRENT, manufactures epoch, signs or creates a worker. Such synchronous DATA work must not run on the nonblocking Stop path. Existing owner/Model E remains responsible for application effects and resources.
