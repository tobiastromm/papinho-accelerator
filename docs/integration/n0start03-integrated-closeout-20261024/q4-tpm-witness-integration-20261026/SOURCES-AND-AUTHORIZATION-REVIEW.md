# Source findings and policy limits

[TCG handle registry](https://trustedcomputinggroup.org/wp-content/uploads/RegistryOfReservedTPM2HandlesAndLocalities_v1p6_rc1_23July2025.pdf), section2.2.2, identifies the owner allocation range0x01800000-0x01bfffff. Candidate0x01804143 is local selection in that convention, not a project registration or reservation. The registry result is a public-review revision; the matching older published registry remains a source link, not full-PDF review claimed here.

[Microsoft TPMA_NV constants](https://github.com/microsoft/TSS.MSR/blob/main/TSS.CPP/Src/TpmTypes.cpp) and [TPM types](https://raw.githubusercontent.com/microsoft/ms-tpm-20-ref/main/TPMCmd/tpm/include/public/TpmTypes.h) support counter/authread/authwrite/written/orderly bits used in the isolated public-area encoder. [NV_ReadPublic](https://raw.githubusercontent.com/microsoft/ms-tpm-20-ref/main/TPMCmd/tpm/src/command/NVStorage/NV_ReadPublic.c) and [NV_Increment](https://raw.githubusercontent.com/microsoft/ms-tpm-20-ref/main/TPMCmd/tpm/src/command/NVStorage/NV_Increment.c) separate public identity from actual update behavior. Dynamic WRITTEN is encoded explicitly; initial counter value is observed, never invented. ORDERLY clear is a candidate persistence choice, not a device power-loss proof.

[Windows NV sample](https://github.com/microsoft/TSS.MSR/blob/main/TSS.NET/Samples/NV%20%28Windows%29/Program.cs) illustrates APIs but contains deletion/recreation, empty-auth fallback and collision-next-index logic that this task expressly forbids. None is copied or executed. [Microsoft TPM lockout](https://learn.microsoft.com/en-us/windows/security/hardware-security/tpm/manage-tpm-lockout) notes owner-password custody constraints. No hierarchy-auth retrieval or guessed/empty auth attempt performed.

AUTHREAD/AUTHWRITE uses a secret, not a complete operation-bound TPM policy. An authenticated command/session adapter and existing protected custody must still be qualified before native use. Without them, public-Name hashing or possession of admin token does not establish ownership. NV policy deletion and platform hierarchy attributes were not selected; authorized hierarchy deletion/Clear remain threats requiring continuity detection, not secretly prevented by these attributes. TPM generation identity remains unestablished; manufacturer/firmware are only availability metadata.
