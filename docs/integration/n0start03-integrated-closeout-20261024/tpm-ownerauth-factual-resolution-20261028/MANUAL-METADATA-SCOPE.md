# Consulta opcional de metadado em token elevado

A execução já observada fora do sandbox abriu/fechou contexto TBS, mas a consulta oficial STORAGE_20 com saídaNULL retornou INTERNAL_ERROR. Não é prova de ausência. Não repetir no mesmo contexto sem hipótese nova. O contexto diferente que ainda pode esclarecer o limite é o console PowerShell5.1x64 já elevado do proprietário; não há bypassUAC nem Start/Stop.

MANUAL-ELEVATED-METADATA-ONLY.txt contém comando literal com hash real. A autorização técnica read-only deste TASK não é uma autorização de NV/Q4: o coletor só carrega tbs.dllSystem32, abre contextoTBS e faz UMA chamada Tbsi_Get_OwnerAuth tipo13 com bufferNULL, sem alocar/receber/obter autorização. NULL é output de metadado, NÃO senha vazia enviada ao TPM. Não existe Get-Tpm, ReadRegistrySecret, buffer de segredo, envioTPM ou setter. Não consulta outros tipos de autorização. Não executar como tentativa de senha.

Recolher só JSON/status. Resultados: NOT_FOUND0x80284015 significa fonte STORAGE_20 não localizada por essa API/token/instante, não inexistência de custodiante externo. Source-present significa apenas disponibilidade de metadado, não custódia/validade/permissãoNV. INTERNAL_ERROR/access/context errors continuam UNKNOWN, nunca zeros virgens ou authvazia. Exit0 do coletor indica que contexto/consulta completaram, não que a disponibilidade foi demonstrada; verificar query_rc/state.

Closecontext0 e FreeLibrary retornado são fechamento controlado no processo; internosWindows/TBS UNKNOWN. Close incerto conserva processo/contexto/módulo, não matar/retry. Nenhum marcador de operaçãoTPM/NV/Q4/intent é criado; a prova matemática anterior permanece consumida e não é reutilizada. Antes da consulta guards de handles124/128, sem grant de orçamento administrativo ou medição de pico total. Não usar este resultado como admissão de provisionamento. Não é obrigatório repetir essa consulta se o proprietário já conhece uma fonte legítima governada; nesse caso fornecer somente proveniência não secreta, nunca o valor.
