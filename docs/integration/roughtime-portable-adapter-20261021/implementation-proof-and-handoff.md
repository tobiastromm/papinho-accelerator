# Offline Roughtime components and remaining qualification gates

The private C89 core is src/issuer/roughtime.h/.c. It allocates nothing, performs no I/O, creates no owner/worker/root/registry/journal/pin and never changes the existing qualified source read. PAPACC_RT_DATA_OK means mathematical/structural DATA only. No callback verifies administrative trust. Cryptographic callbacks supply primitives only, with explicit independently provided key bytes; caller-provided keys remain DATA, never authorized pins by inference.

Implemented: bounded RFC packet/map parsing; required tags/widths/version lists; duplicate/order/alignment/offset/truncation/packet cap checks; exact2048-byte outgoing packet and SRV identifier; full-request Merkle hashing with domain bytes and residual-index rejection; delegation and signed-response verification with terminating-zero contexts; protocol delegation timestamp checks; nonce matching; six-exchange DATA correlation/chain and causal comparisons; conditional interval/hull using existing Q3 arithmetic; offline exchange-state deadlines/replay/Stop retention and capped backoff arithmetic. The independent Merkle helper accepts a bounded historical request for proof checking; the full profile reply verifier still requires2048-byte requests. No draft wire or operational PACC transport is used.

The explicit OpenSSL3.5.8 adapter supplies SHA512-truncated32 and Ed25519 through existing public APIs/artifact, no handwritten primitives, signing or key generation. Native headers are isolated from C89 core. The backend borrows caller-owned explicit private context and4096-byte scratch until synchronous completion; it creates/frees only per-call EVP objects. Default-context fallback is not implemented. The test CMake pins existing import-library/DLL hashes and copies the correct runtime DLL next to its executable. VC6 qualifies the portable DATA code only; OpenSSL adapter/NT4,box,ISA remain unqualified beyond the stated modern isolated backend.

## Lifetime

Inputs, transcript slots, context, keys and source/status references belong to the existing caller/administrative owner. They must remain immutable and protected through every callback and factual quiescence. Outputs are disjoint and published only after checks. Pure event-state functions never release a handle, borrow or credit. Stop marks invalid/stopped and preserves phase/timestamps; pending calls then return RETAINED. Timeout does not prove completion. No native cancel, socket close, audit retirement or credit refund is fabricated. Backend verification is synchronous; provider completion cannot be interrupted by these DATA helpers. The owner must not invoke native crypto on its Stop path or free borrows while calls run.

There is no actual transport producer: event accounting does not submit sends, create sockets, verify native close or enforce process-wide campaign admission. Six-packet scheduling,60-second campaign spacing, persistent administrative/status/restart prerequisites and real Stop/uncertain completion must be integrated under existing owner only after lifetime/capacity review. Native I/O has not been implemented or exercised. These omissions are implementation gates, not falsely classified as environment alone.

The Q bridge is DATA calculus, not a positive qualified observation producer. Source calibration, causality, independently authorized identity/status/CURRENT, qualified entropy, PAL rho/E/continuity and actual applicability remain absent. papacc_issuer_qualified_utc_read stays NOT_SUPPORTED and is not modified. Actual effect-time age/deadline/quality/status/current checks and complete source qualification remain required before issuer/UPDATE use.
