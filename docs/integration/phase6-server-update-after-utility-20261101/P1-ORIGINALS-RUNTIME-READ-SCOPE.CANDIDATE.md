Impersonar administrador/usar privilégio/alterar runtime ou abrir por caminho arbitrário viola separação. Recomendação: permitir leitura mínima do SID específico apenas nos DOIS NOVOS originais não secretos desta sessão, preservando leitores ReOpenFile e todos os mecanismos.
