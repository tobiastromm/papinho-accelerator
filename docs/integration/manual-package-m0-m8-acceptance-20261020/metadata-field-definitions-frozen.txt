Tags: 1 ExpectedServerName DNS ASCII1..253; 2 port u16 nonzero; 3 server leaf DER SHA25632; 4 channel CA DER SHA25632; 5 config domain32; 6 config revision u64nonzero; 7 policy identity32; 8 policy revision u64nonzero; 9 ALPN eight bytes `papacc/1`; 10 SecurePrincipal profile u16=1; 11 package identity32 CSPRNG bytes; 12 client leaf SHA25632; 13 recipient label UTF8 1..128/no controls; 14 issued_at UTCseconds u64; 15 import_not_before UTCseconds u64; 16 import_expires UTCseconds u64. DNS labels LDH1..63, no leading/trailing hyphen, wildcard, empty label, IP literal, NUL or trailing dot. Values refer to actual approved committed configuration; revisions are provenance, not Browser assertion of remote CURRENT. Label is intended recipient metadata, not device authentication. Package signer identity is outer header. No Browser prerequisite/CSR field.
