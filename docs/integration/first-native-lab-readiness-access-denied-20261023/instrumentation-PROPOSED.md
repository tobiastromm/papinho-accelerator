# Focal first-failure instrumentation — PROPOSED, NOT APPLIED

The adjacent patch, manifest and proposal postimages are review artifacts only. They have not been applied to apps/server, linked into a service executable, registered or run under SCM. No authorization correction is proposed without a demonstrated cause.

PAPACC_PSR_TRACE_LAB is default OFF and restricted to the existing private LAB profiles. Wrappers evaluate each original API expression once, preserve return values/GetLastError, and preserve raw NtCreateFile NTSTATUS before the unchanged conversion to 5. Named predicates distinguish policy rejection from API failure. The first failure is latched; propagation cannot overwrite it. Records identify PID/TID, source/API/stage, object, requested mask, native error, predicate and returned error. Existing bounded token buffers may report nonsecret SID/group/privilege facts only when actually queried; missing facts are marked unavailable. No token handle, credential, private key or configuration secrets are exported. No new token acquisition, worker, file journal or authority is introduced.

BEGIN, FIRST_FAILURE and DIAG_END markers distinguish capture failure from a recorded denial. PREPARE_SUCCESS marks non-reproduction only, never operational admission. OutputDebugString preserves incoming LastError. Static recorder 120 bytes is included in proposed storage accounting; remaining stack/receiver/native costs are not zero or fully qualified.

Offline model Debug/Release and actual proposed translation-unit /W4 /WX compilation Debug/Release passed without warnings. Tests include first-error preservation, native-status preservation, return/LastError preservation with a deliberately disruptive fake output sink, missing/bounded token data and success markers. Trace OFF text sections and relocation targets match original. These are not a positive service runtime test or full product build.

Token facts are admissible only if actually captured from that process. If PREPARE_SUCCESS appears without failure, the failure was not reproduced; if markers are missing, evidence is insufficient. Either outcome preserves STOP and grants no automatic retry. No launcher is armed and no Start command is provided here. Preserve all results, no automatic ACL change, deletion or fallback account.
